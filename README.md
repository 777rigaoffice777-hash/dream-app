# ✨ Мастерская — моё приложение

Это веб-приложение (PWA). Оно открывается в Chrome на телефоне и ставится на рабочий стол как обычное приложение.

## Как установить на телефон
1. Открой ссылку на приложение в **Google Chrome**.
2. Нажми кнопку **«Установить»** вверху, или меню ⋮ → **«Добавить на главный экран» / «Установить приложение»**.
3. Иконка появится на рабочем столе.

## Где что лежит
| Файл | Что внутри |
|------|-----------|
| `index.html` | Экраны и кнопки (что видно) |
| `style.css` | Цвета, шрифты, внешний вид |
| `app.js` | Что происходит при нажатиях (логика) |
| `manifest.json` | Название и иконка приложения |
| `icons/` | Иконки (пересоздать: `node make-icons.js`) |

## Как менять и выкладывать
1. Открой папку в VS Code, поменяй файлы.
2. Посмотреть на компьютере: `npx serve .` и открыть http://localhost:3000
3. Выложить на телефон:
   ```
   git add .
   git commit -m "что я поменял"
   git push
   ```
   Через ~1 минуту изменения появятся по той же ссылке. Иногда нужно закрыть и снова открыть приложение.

## Автосохранение
Когда работаешь через Claude Code, всё сохраняется в GitHub само после каждого ответа Claude,
а при запуске подтягивается свежая версия. Вручную сохранить: `bash autosave.sh`.

## Как продолжить на другом компьютере
1. Установи [Git](https://git-scm.com), [GitHub CLI](https://cli.github.com) и VS Code с Claude Code.
2. В терминале:
   ```
   gh auth login
   gh repo clone 777rigaoffice777-hash/dream-app
   cd dream-app
   git config user.name "Ваня"
   git config user.email "777rigaoffice777-hash@users.noreply.github.com"
   ```
3. Открой папку `dream-app` в VS Code — и продолжай. Автосохранение включится само.

## Идеи, с чего начать
- Поменяй цвета в начале `style.css` (`--bg`, `--accent`).
- Добавь свои фразы в `phrases` в `app.js`.
- Сделай в «Лаборатории» мини-игру.
- Попроси Claude: «добавь в моё приложение экран с …».
