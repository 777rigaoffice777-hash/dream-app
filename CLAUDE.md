# Мастерская — PWA Вани

Простое веб-приложение без сборки: `index.html`, `style.css`, `app.js`, `manifest.json`, `sw.js`.
Хостинг: GitHub Pages из ветки `main` → https://777rigaoffice777-hash.github.io/dream-app/

## Правила
- Автор — ребёнок, который учится. Объясняй просто, по-русски, коротко.
- Всё сохраняется в GitHub автоматически: хук Stop запускает `autosave.sh` (commit + push),
  хук SessionStart забирает свежую версию (`autosave.sh pull`). Не отключай это.
- Выкладывай изменения командой `bash deploy.sh "что поменял"` — она поднимает версию везде (bump.sh), отправляет в GitHub
  и ждёт, пока на сайте обновятся все файлы. Телефон обновится сам. Первая строка app.js и studio.js — метка /* build N */, не удаляй.
- Без фреймворков и сборщиков, пока Ваня сам не попросит.
- Все кнопки звучат сами (обработчик «Звук у КАЖДОЙ кнопки» в app.js) — новым кнопкам ничего добавлять не нужно.
  Свой звук: data-sound="bell" (имена из SOUND_FX/UI_SOUNDS), без звука: data-sound="none".
