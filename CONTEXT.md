# Контекст проекта «Мастерская»

Этот файл нужен, чтобы продолжить работу **с любого компьютера** с того же места.
Claude читает его автоматически (на него ссылается `CLAUDE.md`). Обновляй его, когда добавляешь
новый режим или меняешь правила.

_Последнее обновление: 27.11.2026, версия приложения 55._

---

  ставится на рабочий стол как обычное приложение (PWA).
- **Сайт:** https://777rigaoffice777-hash.github.io/dream-app/

- **Как отвечать:** просто, по-русски, без технических слов; в конце говорить, что проверено и что нет.

## 2. Как продолжить на другом компьютере

1. Установить [Git](https://git-scm.com), [GitHub CLI](https://cli.github.com), [Node.js](https://nodejs.org)
   и VS Code с расширением Claude Code.
2. В терминале:
   ```
   gh auth login                       # войти в аккаунт 777rigaoffice777-hash
   gh repo clone 777rigaoffice777-hash/dream-app
   cd dream-app
   git config user.name "777rigaoffice777-hash"
   git config user.email "777rigaoffice777-hash@users.noreply.github.com"
   ```
3. Открыть папку `dream-app` в VS Code и написать Claude, что нужно сделать.
   Автосохранение в GitHub включится само (`.claude/settings.json` в репозитории).

## 3. Как выкладывать изменения (важно!)

- **Только так:** `bash deploy.sh "что поменял"`. Скрипт:
  1. проверяет код на ошибки (`app.js`, `studio.js`) и что все файлы из списка `FILES` в `sw.js` существуют —
     при ошибке **ничего не выкладывает**;
  2. поднимает версию везде (`bump.sh`: `version.json`, `?v=N` в `index.html`, кэш в `sw.js`,
     метка `/* build N */` в первой строке `app.js` и `studio.js`);
  3. отправляет в GitHub и **ждёт, пока на сайте обновятся все файлы**.
- Телефон обновляется сам: приложение раз в минуту и при открытии сверяет `version.json`, и
  перезагружается, только когда на сайте новые **все** файлы (проверяет метки `/* build N */`).
- **Страховка** в `index.html` (отдельно от `app.js`): если основной код не запустился из-за ошибки,
  каждые 30 секунд ищет исправленную версию и перезагружается на неё.
- Под словом «Мастерская» видна версия («версия 55») — по ней понятно, свежая ли версия на телефоне.
- Ссылку для установки отправляли родителю в Telegram («Избранное») с этого компьютера через
  Telegram Desktop; на другом компьютере это делается вручную.

## 4. Как устроено

Без фреймворков и сборщиков: `index.html`, `style.css`, `app.js` (почти все режимы),
`studio.js` (3D, модуль), `sw.js` (работа без интернета), `vendor/` (Three.js 0.170, MIT).

Нижнее меню листается вбок. Вкладки и где их код:

| Вкладка | Что делает | Где настраивать (в `app.js`, если не сказано иное) |
|---|---|---|
| 🔴 Точки | красные точки на сером фоне, счётчик попаданий, скорость x1–x10 | `dotEveryMs`, `dotLifeMs` |
| 🌈 Цвета | «Только красный!» — точки 6 цветов, голосом задание каждые 10 с, ошибки | `COLORS`, `FIRST_TARGET_MS`, `TARGET_EVERY_MS` |
| 🎅 Мороз | Дед Мороз (нарисован в SVG), по нажатию — пожелание голосом | `WISHES`, `GREETINGS` |
| 🧩 Пазлы | 4 уровня (Лёгкие / Средние / Сложные / Очень сложные), 5-е задание — «Найди пары» с картинками; в «Очень сложных» 6 заданий | `PUZZLES`, `PICTURES` |
| 📐 Фигуры | нарисуй фигуру за 15 с, оценка точности в % | `SHAPES`, `SHAPE_TIME`, `shapeScore` |
| 🧊 3D | 3D-мастерская: 37 фигур, двигать, красить, размер, вытягивать (стрелки), поднимать, объединять/разъединять | `studio.js`: `SHAPES3D`, `PALETTE` |
| 📦 Продукты | сохранённые 3D-объекты, просмотр/изменение/удаление | `studio.js` |
| 🎲 Числа | генератор случайных чисел от/до (BigInt) и «∞ без предела» | `NB_INF_CONTINUE` |
| 🔊 Звуки | звуковые кнопки на большом поле (двигается во все стороны), кнопки можно расставлять, свои кнопки: слово или запись голоса | `SOUND_BUTTONS`, `SOUND_FX` |
| 🥤 Стаканы | 2–15 стаканчиков, шарик ровно в одном, перемешивание ровно 7 с | `SHUFFLE_MS`, `CUPS_MIN/MAX` |
| 💡 Идеи | записная книжка идей | |
| 🎨 Рисовать | рисовалка | |
| 🧪 Лаба | **конструктор темы**: свои цвета и эмодзи, готовые и свои темы, «Сбросить всё» (только тема) | `THEME_PRESETS`, `START_COLORS`, `START_EMOJIS` |

Общее для всего приложения:
- **Музыка** своя (синтезатор, без файлов): `TRACKS`, какая где — `MUSIC_FOR`; в «Цветах» бесконечная
  самосочиняющаяся (`TRACKS.endless`); в «Морозе» и «Звуках» музыки нет. Кнопка 🎵 вверху выключает всё.
- **Звук у каждой кнопки**, даже у будущих (один общий обработчик). Свой звук: `data-sound="bell"`,
  без звука: `data-sound="none"`. Кнопки со своим звуком перечислены в `OWN_SOUND`.
- **Голос** — `say(text)` (русский голос телефона).
- **Тема** — CSS-переменные `--bg --bg2 --card --accent --text --on-accent --deco`; цвет надписей
  на кнопках (`--on-accent`) подбирается сам.
- **Всё, что создаёт Ваня, хранится в телефоне** (localStorage): `theme`, `myThemes`, `myColors`,
  `myEmojis`, `products3d`, `studioDraft`, `soundButtons`, `sbPositions`, `pzSolved`, `nbHistory`,
  `cupsScore`, `ideas` и др. Интернет для этого не нужен.

## 5. Что ещё не доделано

- **Звуковые кнопки — слова.** Родитель сказал «насчёт звуков, то есть слов, объясню потом».
  Сейчас там заготовки («Привет!», «Ура!», «Ой!»). Когда пришлёт слова — дописать в `SOUND_BUTTONS`.
- **Работа без интернета (версия 54–55)** выложена, но полная проверка «выключить интернет и открыть
  приложение» **не закончена** (проверку прервали). Надо проверить: открыть приложение с интернетом
  один раз, потом выключить интернет и пройти все вкладки, включая 3D.
- Цвет текста в теме выбирается вручную — можно собрать нечитаемое сочетание. Предлагали
  предупреждение или автоподбор, решения не было.

## 6. Уроки (чтобы не наступать снова)

- **Нельзя выкладывать без проверки кода.** Однажды (версия 47) ушёл код с ошибкой и сломал приложение
  на 1–2 минуты. Поэтому `deploy.sh` теперь проверяет код сам, а в `index.html` есть страховка.
- **GitHub Pages выкладывает файлы не одновременно** и держит копии до 10 минут. Поэтому ждать
  обновления **всех** файлов (это делает `deploy.sh`) и проверять метки `/* build N */`.
- **Не ждать конца анимации для отсчёта времени** — телефон может тормозить анимации; время считать
  по `Date.now()` (так сделаны таймер «Фигур» и перемешивание «Стаканчиков»).
- **Тестовый браузер (Playwright) считается фоновым окном:** там не рисуются кадры, тормозят таймеры
  и анимации, снимки экрана иногда зависают (помогает `page.screenshot` через run_code после
  `bringToFront`), а мышь после перезагрузки страницы может перестать нажимать. Это не ошибки приложения.
- Скрытые в тестах вещи проверять «изнутри» (`page.evaluate`), а внешний вид — скриншотом 390×800.
